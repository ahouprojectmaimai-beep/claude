# 公式LINEの準備手順（まいまいさん用・スマホでOK）

所要時間：30分くらい。費用：0円（無料プラン）。

## ステップ1：公式アカウントを作る
1. スマホで「**LINE公式アカウント**」アプリをインストール（または ブラウザで `manager.line.biz`）
2. 会社のLINEアカウントでログイン →「アカウントを作成」
3. アカウント名：**アホウ入金チェック**（スタッフに分かる名前なら何でもOK）
4. 業種などを入力して作成。プランは「**コミュニケーションプラン（無料）**」のまま

> ⚠️ ほりまるのお客様向けの公式アカウントとは**別に新しく作ってください**（混ざると、お客様のメッセージがこのシステムに届いてしまうため）

## ステップ2：設定を変える（ブラウザの `manager.line.biz` で）
1. 作ったアカウントを開く →「設定」
2. **アカウント設定** →「グループ・複数人チャットへの参加」→ **参加を許可する**
3. **応答設定** →
   - 「チャット」→ オフ
   - 「Webhook」→ **オン**
   - 「応答メッセージ」→ **オフ**（オンのままだとグループで勝手に返事してしまう）
   - 「あいさつメッセージ」→ オフ
4. **Messaging API** →「Messaging APIを利用する」→ プロバイダーは「新規作成」（名前：アホウプロジェクト）

## ステップ3：合言葉（2つ）を確認する
ブラウザで `developers.line.biz/console` を開き、ステップ2で作ったチャネルを選ぶ。
- 「チャネル基本設定」タブ → **チャネルシークレット**
- 「Messaging API設定」タブ → **チャネルアクセストークン（長期）** →「発行」

> ⚠️ **この2つはチャットに貼らないでください。** ステップ5の方法で登録します。

## ステップ4：Cloudflare のトークンを作る（システムを公開するため）
1. ブラウザで `dash.cloudflare.com` にログイン（「horimaru-line」がある、いつものアカウント）
2. 右上の人のアイコン →「マイプロフィール」→「APIトークン」→「トークンを作成」
3. テンプレート「**Cloudflare Workers を編集する**」を選び、権限に **D1 編集・R2 編集・Queues 編集** を追加 → 作成
4. 表示されたトークンをコピー（**チャットには貼らない**）
5. ダッシュボードのトップ右側にある **アカウントID** もコピー

## ステップ5：このクラウド環境に登録する
スマホのブラウザで `claude.ai/code` → このセッション → 画面上部の環境名メニュー →「Edit」→ 環境変数に次を追加して保存：
```
LINE_CHANNEL_SECRET=（ステップ3のチャネルシークレット）
LINE_CHANNEL_ACCESS_TOKEN=（ステップ3のアクセストークン）
CLOUDFLARE_API_TOKEN=（ステップ4のトークン）
CLOUDFLARE_ACCOUNT_ID=（ステップ4のアカウントID）
ANTHROPIC_API_KEY=（用意できていれば。後からでもOK）
```
登録したら**新しいセッション**で「LINEの準備ができた」と伝えてください。

## ステップ6（私が行う）
1. Cloudflare にシステムを公開し、Webhook URL を作る
2. Webhook URL を LINE Developers に設定してもらう（URLをお伝えします）
3. **テスト用グループ**（まいまいさん＋Bot だけ）で動作確認
   - Bot が「グループID」を返信するか
   - 「白梅町」＋写真で「📥 受付：白梅町店 写真1枚」と返るか
   - 「9/28〜9/30分 現金チェックOK」を受け取れるか
4. 問題なければ、今の店舗グループに Bot を招待（PHASE 7 の本番テストのとき）
